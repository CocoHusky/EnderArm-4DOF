# Public source snapshot

This repository starts with a fresh source snapshot, not imported development
history. Commit authorship uses a project identity. The GitHub account hosting
the repository remains public; this is not an anonymous publication.

Private feature settings, saved programs, calibration, network configuration,
logs, device-specific serial defaults, build products, and SDK/toolchain
downloads are not included. Configure the sensor port locally with
`ENDERARM_SENSOR_PORT`; the public default is only a generic alias.

Published photos have no EXIF/XMP/camera/location metadata and visible equipment
identifiers are obscured. The video is a six-second silent cropped excerpt,
not the original full capture. Its container retains only technical playback
information; location/capture/device metadata and auxiliary tracks are omitted.
Original media is not uploaded. Visual review reduces exposure but cannot
guarantee that a scene is unrecognizable or that published material cannot be
copied. Do not add original captures, private configuration, or personal paths.

47 hardware-free tests and Python/JavaScript syntax checks cover the controller,
optional sensors, gestures, guards and shared boundary. Firmware 0.3.0 was
built/flashed and live sensor data verified on the reference installation.
Hands-on gesture accuracy and intentional impact-stop validation remain
operator checks. See the detailed controller and update guides.
