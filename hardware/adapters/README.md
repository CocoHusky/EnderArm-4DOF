# Ender-specific adapters

## 624ZZ flange shim

`624ZZ Flange Shim.stl` allows a standard 624ZZ bearing to be used where the source design calls for an F624ZZ flanged bearing. Use one shim with each 624ZZ bearing.

These parts modify the source arm hardware so the conversion can reuse original Ender components and inexpensive commodity parts.

## Bearing shell

`bearing-shell-top.stl` and `bearing-shell-bottom.stl` form a printed bearing race. Fill the race with 6 mm precision steel balls during assembly.

This replaces the purchased bearing assembly used by the original robot design with a low-cost printed alternative.

## Bearing spacer

`bearing-spacer.stl` is used with a standard 686ZZ bearing.

The 686ZZ itself has a 6 mm bore. The spacer adapts that interface for an M5 fastener and adds flange-like retention so the original Ender M5 hardware can be reused.

## Motor spacer

`motor-spacer.stl` spaces the donor stepper correctly for the arm belt drive. It is specifically intended to let the original stepper motor remain usable with its 20-tooth GT2 pulley already installed.

## Files

The public STL filenames are:

```text
bearing-shell-top.stl
bearing-shell-bottom.stl
bearing-spacer.stl
motor-spacer.stl
```

STEP/source CAD files can be stored alongside these once available.
